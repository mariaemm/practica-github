## Propósito
Repositorio de prácticas para aprender a usar Git y GitHub organizando archivos de código.

## Descripción
Contiene un archivo `index.html` con una tabla de trabajadores (nombre, departamento y turno) 
y sus estilos básicos. Sirve como ejercicio de estructura HTML y control de versiones.
